# Free Access to Aeromexico's Wi-Fi Network on iOS Devices

## Introduction

Initially, it is necessary to connect to the aircraft's wireless network by following these steps:

1. Open the Wi-Fi settings on the device and connect to the network named exactly **Aeromexico-WiFi**.
2. Enter the airline's captive portal form www.aeromexicowifi.com. On this screen, select the **15 minutes free** option.

![Aeroméxico's captive portal](../assets/captive-portal.png)

> Once this free period (15 minutes) has elapsed, the device will no longer have an internet connection. When this occurs, access to the network must be restored as described in the following sections of this document.

## MAC Address Configuration

Within the network settings, iOS may provide a setting called **Private Wi-Fi Address, Rotate WiFi Address** or an equivalent option.

Depending on the iOS version, options related to private or randomized MAC addresses may be available. Enable the **Private Wi-Fi Address** option when available.

The private address is used for connections corresponding to that network configuration, according to the behavior implemented by the iOS version and the device.

![Configuración en Android](../assets/rotate-wifi-address.jpg)

## Reconnecting to the Network

After modifying the privacy settings for the connection:

1. Disconnect the device from the Wi-Fi network.
2. Reconnect to the network.
3. Verify that the connection is working correctly.
4. Complete the corresponding authentication process by selecting free browsing for 15 minutes.

If the connection presents problems, delete the saved network configuration and reconnect.
